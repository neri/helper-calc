# 助っ人貸出回数計算機

入力した時間と獲得報酬から、助っ人の貸し出し回数を推定するツールです。

## 計算ロジック

### 報酬増加のルール
* **時間経過**: 1分ごとに20ポイント増加。
* **貸し出し**: 1回あたり50,000ポイント増加。

### 推定ロジック
- 推定貸出回数 `C = floor( (獲得報酬 B - (登録時間 A × 60分) × 20) / 50,000 )`
- `C`が負の場合: エラー「貸出回数が負です」(結果非表示)
- 時間報酬 `D = 獲得報酬 B - (C × 50,000)`
- 貸出回数報酬 `E = C × 50,000`
- 報酬の範囲を計算: 最大報酬 = `((A × 60) + 59) × 20 + C × 50,000` (登録時間時)、または `(A + 10) × 20 + C × 50,000` (設定日時時)
- 入力報酬が最大報酬以下なら確定、そうでなければエラー「獲得報酬の値が計算範囲外です」。

## ビルド方法

ビルド:
```bash
mise run build
```

## 使用方法

1. 開発サーバーを起動:
    ```bash
    mise run server
    ```

2. ブラウザで http://localhost:5173 を開く。

3. 報酬と時間を入力して、貸出回数を推定。
